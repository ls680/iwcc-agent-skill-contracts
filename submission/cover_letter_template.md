Please consider our manuscript, "From Traces to Witnessed Contracts:
Incremental Precondition-Effect Compilation for LLM Agent Skills," as a full
research article in [JOURNAL].

Reusable LLM-agent skills turn one faulty action program into a persistent
software defect. The manuscript introduces Incremental Witnessed Contract
Compilation (IWCC), a pre-execution validator that compiles successful native
traces into deterministic contracts over objective roles, milestones,
precedence, navigation, and producer-consumer dataflow. Each learned clause
retains the hashes of its successful witnesses and each rejection identifies a
violated clause and program position.

The evaluation separates exposed development evidence from a frozen,
zero-overlap confirmation. On 60 ALFWorld and ScienceWorld tasks and 300
candidate programs, IWCC reaches 88.12% balanced accuracy, compared with 77.48%
for the predeclared strongest comparator. The 10.64-point gain has a
task-stratified 95% confidence interval of 8.88--12.50 points and a paired task
permutation p-value below 0.00001. IWCC accepts all 98 healthy or behaviorally
equivalent controls and runs at 0.487 ms median latency on one CPU process.

We believe the work fits [JOURNAL] because it treats maintained agent skills as
software artifacts with testable contracts, explicit provenance, and
release-time failure screening. The claim is deliberately bounded: IWCC
detects modeled structural defects but does not certify semantic success or
replace native execution. We release source, frozen protocols, complete native
records, all model outputs, exact result verification, and bilingual manuscript
sources.
